# 🎬 쇼츠 메이커 (shorts-maker)

폰·PC 브라우저에서 이미지와 자막, 목소리, BGM을 합쳐 **9:16 세로 쇼츠 영상**을 만들고 바로 내려받는 웹앱입니다.
설치도 로그인도 필요 없고, 모든 편집과 녹화는 **내 브라우저 안에서만** 처리됩니다. (서버 업로드 없음 · 🎙️ AI 성우만 OpenAI API를 브라우저에서 직접 호출)

- 앱 열기: `index.html` (GitHub Pages 배포 시 저장소 주소)
- 배포 주소: https://gobongi9988.github.io/shorts-maker/
- 기본 샘플: 1편 「10억 다이아를 삼킨 도둑」 5컷이 자동으로 열려 바로 재생·내보내기 테스트 가능
- 프리셋 전환: **1편 · 10억 다이아** / **2편 · 공항 150만** 버튼으로 5컷 대본·이미지를 통째로 교체
- 샘플 이미지: `assets/sample-01/cut1.png`~`cut5.png`, `assets/sample-02/cut1.png`~`cut5.png` (1080×1920)

## 주요 기능

| 구분 | 내용 |
|---|---|
| 프리셋 | 1편(10억 다이아)·2편(공항 150만) 5컷 대본+이미지 전환 |
| 컷 편집 | 컷 추가·삭제·위/아래 이동, 컷별 이미지 교체(썸네일 클릭), 자막 줄바꿈 입력 |
| 자막 스타일 | 글자 크기, 굵기, 위치(상단·중앙·하단), 배경 박스(검정 반투명·흰색·없음), 자막 효과 6종, 컷별 따로 설정 |
| 자막 효과 | 고정 · 팝업 통통 · 타자기 · 단어 강조 · 슬라이드 업 · 펀치 강조 (미리보기·내보내기 동일) |
| 재생 시간 | 컷별 슬라이더 + 숫자 입력(0.5~120초), 음성 길이에 자동 맞추기 |
| 목소리 | ① 브라우저 한국어 TTS 미리듣기(목소리·속도 0.8~1.5x·피치) ② 🎙️ **OpenAI AI 성우**(성우 10종·속도 0.75~1.4x·모델 3종, 컷별/전체 한 번에 생성 → MP3로 영상에 구움) ③ 컷별 마이크 녹음(MediaRecorder) ④ 컷별 음성 파일 업로드(MP3·WAV·M4A) ⑤ 톤 변조 5종(원본·하이톤·중저음·다람쥐·라디오) |
| BGM | 파일 업로드 + 볼륨, 목소리 볼륨 따로 조절 |
| 미리보기 | 9:16 실시간 캔버스, 재생·일시정지·탐색, Ken Burns 줌 ON/OFF, 모바일 미니 미리보기 |
| 내보내기 | 720×1280 / 1080×1920 선택, 자막·이미지·목소리·BGM을 한 파일로 녹화 후 원클릭 다운로드 |
| 저장 | localStorage 자동 저장(텍스트·설정), 이미지·음성은 IndexedDB, 프로젝트 JSON 내보내기/불러오기 |

## 사용 순서

1. 앱을 열면 샘플 1편이 로드됩니다. ▶ 버튼으로 바로 재생해 보세요.
   - 컷 리스트 위 **샘플** 버튼에서 **1편 · 10억 다이아** / **2편 · 공항 150만**을 골라 통째로 바꿀 수 있어요.
2. 컷 카드의 **썸네일**을 눌러 이미지를 바꾸고, 자막을 고치고, 재생 시간을 맞춥니다.
3. 목소리는 **🔈 TTS**로 미리 들어본 뒤, 영상에 담을 때는 **🎙 녹음**·**📁 음성 파일**·**🎙️ AI 성우(OpenAI)**를 씁니다.
   - 브라우저 TTS는 미리듣기 전용이라 영상 파일에 직접 구워지지 않습니다. AI 성우로 만든 음성은 MP3로 저장돼 영상에 그대로 들어갑니다.
4. 필요하면 **🎵 BGM**을 넣고 볼륨을 조절합니다.
5. **🎥 영상으로 내보내기**를 누르면 실제 재생 시간만큼 녹화됩니다. 끝나면 자동 다운로드되고 결과 카드에서 다시 받을 수 있습니다.
6. 다른 기기로 옮기려면 **프로젝트 저장(JSON)** → 새 기기에서 **불러오기**.

## 🎙️ AI 성우 (OpenAI TTS)

OpenAI 음성 합성 API(`POST https://api.openai.com/v1/audio/speech`)를 브라우저에서 직접 호출해 성우 음성을 만듭니다. 서버가 없어도 GitHub Pages에서 바로 동작합니다.

1. **OpenAI API 키**를 넣고 **키 저장**(localStorage, 이 브라우저에만) — 키는 음성 생성 때만 OpenAI로 전송됩니다.
2. **AI 성우**(nova·coral·sage·shimmer·alloy·ash·echo·onyx·fable·ballad) · **말하기 속도**(0.75~1.4x, 기본 1.05x) · **모델**(tts-1 기본 / tts-1-hd / gpt-4o-mini-tts)을 고릅니다.
3. 컷 카드의 **🎙️ AI 음성** = 그 컷만, **전체 컷 AI 음성 한 번에 만들기** = 자막이 있는 모든 컷을 순서대로(진행률 표시, 중간 중지 가능).
4. 만들어진 음성은 업로드한 음성과 똑같이 IndexedDB에 저장돼 새로고침해도 남고, 미리보기·내보내기에 그대로 들어갑니다. **음성 길이에 맞추기**가 켜진 컷은 재생 시간도 자동으로 맞춰집니다.

- `gpt-4o-mini-tts`만 톤 지시문(`instructions`)을 지원합니다. 이 모델은 `speed` 값이 거의 반영되지 않아, 앱이 말투 지시문에 속도를 함께 적어 보냅니다(정확한 배속은 tts-1 계열이 확실).
- `ballad`는 `gpt-4o-mini-tts` 전용이라 tts-1·tts-1-hd에서는 선택이 잠깁니다.
- OpenAI가 `tts-1`·`tts-1-hd`·`gpt-4o-mini-tts`를 **2027-01-06 종료** 예정으로 공지했습니다(그 전까지는 동작). 그 뒤에는 OpenAI가 안내하는 대체 API로 바꿔야 합니다.

## 브라우저 지원

- **Chrome / Edge / Android Chrome**: WebM(VP9·Opus)으로 저장. H.264 MP4 인코더가 있는 환경에서는 MP4로 저장.
- **Safari(iOS 17+ / macOS)**: MP4(H.264·AAC)로 저장.
- MIME 타입을 자동 감지해 확장자(`.mp4` / `.webm`)를 맞춥니다. 지원되지 않는 브라우저에서는 안내 메시지를 보여줍니다.
- 마이크 녹음은 HTTPS 또는 localhost에서만 동작합니다(GitHub Pages는 HTTPS).
- 내보내기는 브라우저 화면을 실시간으로 녹화하는 방식이라, **녹화 중 탭을 전환하거나 화면을 잠그면 중단될 수 있습니다.**

## 저장 방식 · 개인정보

- 자막·설정은 `localStorage`, 이미지·음성·BGM 원본은 `IndexedDB`에 저장됩니다. 브라우저 데이터를 지우면 함께 사라집니다.
- 이미지·음성 파일은 로컬에서만 처리되고 외부로 전송되지 않습니다. 단, **🎙️ AI 성우**를 쓸 때는 그 컷의 자막 텍스트와 API 키가 OpenAI(`api.openai.com`)로 전송됩니다.
- 프로젝트 JSON에는 이미지·음성이 base64로 함께 담겨 다른 기기로 옮길 수 있습니다.

## 알려진 제약

- TTS는 미리듣기만 지원합니다(브라우저 보안 정책상 음성을 파일로 직접 저장할 수 없음). 영상에 넣으려면 녹음/업로드/**AI 성우**를 사용하세요.
- AI 성우는 OpenAI API 키가 필요하고, 호출할 때마다 OpenAI 사용료가 나갑니다(글자 수 기준). 키는 이 브라우저에만 저장됩니다.
- AI 성우 호출은 브라우저에서 `api.openai.com`으로 직접 나갑니다. 사내망·확장 프로그램·방화벽이 막으면 연결 오류가 날 수 있습니다.
- 목소리 톤 변조는 녹음·업로드한 음성에만 적용됩니다(브라우저 TTS 미리듣기에는 적용되지 않음). 톤을 바꾸면 ‘음성 길이에 맞추기’가 켜진 컷의 재생 시간도 변조된 길이로 다시 맞춰집니다.
- Chrome에서 WebM으로 저장하면 일부 플레이어가 길이를 바로 표시하지 않을 수 있습니다(재생·업로드에는 문제 없음).
- 1080×1920 내보내기는 기기 성능에 따라 느려질 수 있어 모바일 기본값은 720×1280입니다.
